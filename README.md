# Student Management System

A Java-based Student Management System developed to manage student information and perform basic student-related operations.

## Overview

This project was developed to practise Java programming and apply object-oriented programming concepts in a practical application. It provides a simple way to manage student records and perform essential operations.

## Features

* Add new student records
* View student details
* Update existing student information
* Delete student records
* Manage student data efficiently

## Technologies Used

* Java
* Object-Oriented Programming (OOP)

## Project Structure

The project is organised into separate classes to maintain a clear structure and improve code readability.

## Getting Started

1. Clone this repository.
2. Open the project using a Java-compatible IDE.
3. Make sure the JDK is properly configured.
4. Run the main class to start the application.
